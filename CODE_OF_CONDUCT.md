# Code of Conduct / 行为准则

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

本项目遵循 [Contributor Covenant 2.1](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/) 的精神。

## Our standard / 我们的约定

- Be respectful and constructive, in English or Chinese. 保持尊重与建设性，中英文均可。
- Assume good faith; critique code and ideas, not people. 善意揣测，对事不对人。
- No harassment, discrimination, or personal attacks. 禁止骚扰、歧视和人身攻击。
- Do not post other people's private information, and **never paste real conversation logs, tokens or API keys** into issues. 不要公开他人隐私，**更不要把真实对话记录、令牌或 API Key 贴进 issue**。

## Enforcement / 执行

Maintainers may edit or remove comments, issues and pull requests that violate this, and may block repeat offenders. Report problems through GitHub's "Report content" or the private security reporting channel described in [SECURITY.md](SECURITY.md).

维护者可以编辑或删除违反准则的内容，并可封禁屡犯者。请通过 GitHub 的举报功能，或 [SECURITY.md](SECURITY.md) 中的私密渠道反馈。
